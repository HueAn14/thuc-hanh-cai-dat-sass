SASS CLI & npm Practice

Thực hành cài đặt và biên dịch SCSS sang CSS bằng SASS Command Line Interface

SASS Version 1.105.1 • Node.js v24.21.0

1. Kiểm tra Môi Trường

Kiểm tra Node.js và npm đã được cài đặt trên hệ thống:

node -v
npm -v

Kết quả: Node v24.21.0, npm 11.19.0.

2. Cài Đặt SASS Toàn Cục

Cài đặt gói Dart Sass thông qua npm:

npm install -g sass

Kiểm tra phiên bản cài đặt thành công:

sass --version

3. Biên Dịch Đơn Lẻ (Single File)

Chuyển đổi một tệp SCSS thành file CSS:

sass styles.scss styles.css

Tạo ra tệp styles.css và sourcemap tương ứng.

4. Chế Độ Theo Dõi (Watch Mode)

Tự động biên dịch khi có bất kỳ thay đổi nào:

sass styles.scss styles.css --watch

Giúp tiết kiệm thời gian, không cần gõ lệnh thủ công mỗi lần sửa SCSS.

5. Biên Dịch Thư Mục (Batch Mode)

Biên dịch toàn bộ cấu trúc thư mục scss/ sang css/:

sass scss/:css/ --watch

Hỗ trợ chia nhỏ dự án thành các tệp modular _variables.scss, _mixins.scss.

6. Xử Lý Lỗi ExecutionPolicy

Khắc phục lỗi chạy script trên Windows PowerShell:

Set-ExecutionPolicy Unrestricted

Hoặc thực thi trực tiếp thông qua npm.cmd và sass.cmd.
